# TradingView + tradingview-mcp: установка на своём компьютере

Зачем: когда бот присылает 🚨 в Telegram, ты открываешь локальный Claude Code
— и Claude смотрит сетап **на твоём живом графике TradingView**: скриншот,
разметка LuxAlgo Smart Money Concepts, уровни, второе мнение до входа.

Роли и границы зафиксированы в
[спеке 2026-08-30](superpowers/specs/2026-08-30-backtest-and-tv-eyes-design.md):
детектор остаётся на Railway (D18), TradingView — только глаза аналитика на
твоей машине (D19). Мост работает **только пока комп включён и TradingView
Desktop запущен** — это нормально, он и не должен работать иначе.

## Что понадобится

- Windows-компьютер (инструкция под него; Mac/Linux — те же шаги, другие
  скрипты запуска).
- **Бесплатный аккаунт TradingView** — зарегистрируйся на tradingview.com.
- **TradingView Desktop** — скачай с tradingview.com/desktop и залогинься.
- **Node.js 18+** — с nodejs.org (LTS), поставь с настройками по умолчанию.
- **Claude Code** на этом компе (у тебя уже есть — репозиторий 926_bot
  склонирован, gh настроен).

## Установка (один раз, ~15 минут)

1. Склонируй мост (в git bash или PowerShell):

   ```bash
   git clone https://github.com/tradesdontlie/tradingview-mcp.git
   cd tradingview-mcp
   npm install
   ```

2. Запусти TradingView с debug-портом (каждый раз вместо обычного ярлыка):

   ```bash
   scripts\launch_tv_debug.bat
   ```

   Это обычный флаг Chromium `--remote-debugging-port=9222` — без него мост
   не подключится, и ничего не происходит без этого явного шага.

3. Подключи мост к Claude Code — в `~/.claude/.mcp.json` (или в `.mcp.json`
   проекта 926_bot) добавь, подставив свой путь:

   ```json
   {
     "mcpServers": {
       "tradingview": {
         "command": "node",
         "args": ["C:/путь/до/tradingview-mcp/src/server.js"]
       }
     }
   }
   ```

4. Проверка: открой Claude Code и попроси —
   *«Use tv_health_check to verify TradingView is connected»*.
   Должен прийти ответ, что соединение живо.

5. Добавь на график индикатор **LuxAlgo — Smart Money Concepts** (бесплатный,
   ищется в Indicators → Community). На бесплатном тарифе лимит ~2 индикатора
   на график — SMC помещается.

## Рабочий процесс после установки

1. Пришёл 🚨 в Telegram.
2. Открываешь Claude Code в папке 926_bot и пишешь: «проверь сетап USDJPY»
   (или какая пара в алерте).
3. Claude через мост: выставит символ и таймфреймы, снимет скриншот, прочтёт
   разметку LuxAlgo (ордер-блоки, FVG, ликвидность), сравнит с зоной,
   входом, SL и TP из алерта — и даст вердикт.
4. Решение о входе — твоё. Алерт бота остаётся сигналом записи; график —
   второе мнение.

## Ограничения и честные оговорки

- Бесплатный тариф: форекс- и крипто-котировки в порядке; интрадей-replay и
  мультиграфики — то, ради чего позже может иметь смысл платный план.
  Решение отложено до результатов бэктеста.
- Мост держится на недокументированных внутренностях TradingView Desktop —
  может сломаться после обновления TV. Если стабильность станет важна,
  зафиксируй версию приложения.
- README самого моста предупреждает: программное потребление данных TV может
  конфликтовать с их Terms of Use. Мы используем его как ручной инструмент
  анализа в твоей залогиненной сессии — не как источник данных для бота
  (решение D18), и это ограничение не обходим.
