# Бэктест: как прогнать и как читать отчёт

Фаза 2 плана ([спека 2026-08-30](superpowers/specs/2026-08-30-backtest-and-tv-eyes-design.md)).
Бэктест гоняет **боевой движок** по истории — правила не трогаются (D20).

## Запуск

```bash
# боевой ростер одной командой (ETHUSD без ключа; USDJPY и USDCAD — нужен ключ):
TWELVEDATA_API_KEY=твой_ключ python smc_backtest.py --days 365 --report-dir data/backtest/reports

# все пять пар реестра:
TWELVEDATA_API_KEY=твой_ключ python smc_backtest.py --all-pairs --days 365 --report-dir data/backtest/reports

# одна пара:
python smc_backtest.py --pair ETHUSD --days 365
```

- Первый запуск качает историю в `data/backtest/` (~15 запросов на пару-год
  M5, лимит 800/день не страдает); дальше всё из кэша, докачивается только
  новое. `--refresh-cache` — принудительная перекачка.
- Пара без данных (нет ключа, лимит) просто скипается с пометкой — остальные
  отчёты выходят. Пара-год считается ~4–5 минут.
- Из облачной сессии Claude Code данные недоступны: сетевая политика
  окружения режет api.binance.com и api.twelvedata.com. Если хочешь, чтобы я
  гонял отчёты сам — разреши эти два хоста в настройках окружения на
  claude.ai/code (Environment → Network policy), либо запускай локально.

## Как читать отчёт

- **Шапка** — что НЕ симулировано (новостной блэкаут → сигналов чуть больше,
  чем было бы вживую; дисциплина — считается, что каждый сигнал взят;
  funding; корреляция пар). Помни об этом при выводах.
- **ALL SIGNALS** — главная строка: `exp.R` (средний R на решённый сигнал,
  положительный = стратегия зарабатывает), `PF` (профит-фактор, >1 —
  прибыльно), `win` (только tp против sl), `totR` (сумма R за период).
  `exp=` — сколько сигналов истекло неисполненными (лимитка не добита).
- **by tier** — ⭐ против regular: звезда должна бить общую выборку, иначе её
  условия не работают.
- **missed for ⭐** — по каждому условию (`room`/`sweep`/`pd`/`stale`/`trend`):
  сигналы, у которых оно провалено, против остальных. Условие «работает»,
  если колонка missing заметно хуже, чем held.
- **one condition away from ⭐** — самый ценный срез: сетапы, которым до
  звезды не хватило ровно одного условия. Если какая-то строка стабильно
  зарабатывает — это повод обсудить порог. **Решение — только твоё**: бэктест
  даёт улики, правила меняешь ты (CLAUDE.md: стратегия — закон).
- **warning autopsy** — то же самое для ⚠️ на алертах (stale entry, тонкий
  RR, нет ликвидности впереди).
- **by month** — стабильность по режимам рынка: одна прибыльная неделя на
  фоне минусовых месяцев — не система.
