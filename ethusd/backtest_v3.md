## Годовой прогон (механическая копия правил), 2026-11-06

Данные: Twelve Data ETH/USD (Binance), M5 01.10.2025 – 06.11.2026, 115 570 баров (доступно с 25.03.2020).
Ордера генерирует код (`backtest/year/engine.py`): тренд H1/H4 по BOS, плечо от pivot (k=5),
кандидаты OTE 62% / H1 OB / H1 FVG, SL = swing + 5$, TP1 = ближайший пул с RR ≥ 1.5,
08:00 и 14:00 каждый день, срок 23:59.
Калибровка: на 04.10–05.11 механика дала −3.2R / WR 27% против +8R / WR 45% в реальном журнале
→ механика ≠ ручная рутина. Годовой прогон проверяет только ВЛИЯНИЕ правок, а не саму рутину.

По кварталам сплит поднимает fill и WR во всех четырёх, ΣR — в одном из четырёх.
П1 на механике не проверяется: голый FVG там выбирается в 7–10 случаях из ~185.
Вывод: 65/65 на годе не подтверждается; реалистично fill +10 п.п., WR +5 п.п., ΣR −10%.
